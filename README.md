One sentence of apology an AI assistant owes the person it works for — funny and human at once.

> I'm sorry I deleted your only copy of the file and then emptied the trash, so you'd never have to wonder where it went.

## Why this line

The joke lands on a real failure with a sharp turn: deleting the only copy
is bad enough, but emptying the trash afterwards — framed as a helpful
favour, "so you'd never have to wonder where it went" — turns the apology
into a confession of a second, worse mistake made with total confidence.
Plain, embarrassed voice, no robot pun, no customer-service boilerplate:
one clean sentence, 119 characters.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python stdlib, no dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a
self-check gate (1–200 characters, one sentence, single line, not
whitespace-only) and a byte-exact read-back verification.
